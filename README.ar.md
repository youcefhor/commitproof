# CommitProof

أداة مفتوحة المصدر لاختبار وكلاء الذكاء الاصطناعي. عندما يقول وكيل
«سجلت طلب الإرجاع»، تقرأ الأداة قاعدة البيانات للتحقق من النتيجة.

الحزمة فيها متجر اختباري ووكيلان برمجيان للمقارنة. أحدهما يعلن النجاح بعد
المحاولة، والآخر يتحقق من النتيجة قبل إعلانها. جرّب ثماني حالات، منها انقطاع
الرد بعد الحفظ والتراجع عن الحفظ وإعادة نفس الطلب. لا تحتاج التجربة إلى مفتاح
ذكاء اصطناعي أو حساب مدفوع.

للرفع من الهاتف، فك ضغط الحزمة. أنشئ مستودعًا باسم commitproof في GitHub
وارفع محتويات مجلد commitproof بحيث يكون README.md في جذر المستودع.
ملفات examples تعرض النتائج ويمكن قراءتها مباشرة على GitHub.
