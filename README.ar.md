# CommitProof Guard

إذا أمر وكيلٌ أداةً بإرجاع مبلغ ثم ضاع الرد، قد يكرر الأمر. تحفظ الأداة رقم العملية قبل إرسالها. إذا ضاع الرد أو توقف البرنامج، توقف إعادة الإرسال حتى يتحقق المشغّل مما حدث. وإذا كانت النتيجة محفوظة، تعيدها مباشرة.

جرّب على Python 3.10 أو أحدث: `python -m unittest -v`. أحد الاختبارات يشغّل عملية منفصلة تسجّل إرجاعًا تجريبيًا في قاعدة بيانات ثم تتوقف فجأة. بعد إعادة التشغيل، يفحص الاختبار أن الإرجاع ما زال مسجلًا مرة واحدة.

يعمل الحارس مع تطبيقات Python التي تستخدم رقمًا ثابتًا لكل عملية وملف SQLite على جهاز واحد. يوفّر التطبيق طريقة التحقق من العملية المعلّقة. راجع README.md لمثال الربط.
